# Формат данных SkyLog

Каждая категория — отдельный файл `assets/data/<id>.json`, порядок задаёт `index.json`.

```json
{
  "id": "main",
  "title": "Основной сюжет",
  "icon": "dragon",
  "description": "1 предложение о категории",
  "groups": [
    { "title": "Название группы (акт, ветка, регион)", "items": [ /* Item */ ] }
  ]
}
```

Item:

```json
{
  "id": "main_unbound",            // уникален во ВСЕХ файлах: <id категории>_<snake_case англ. названия>
  "title": "Побег",                // название из официальной русской локализации
  "en": "Unbound",                 // оригинальное английское название
  "type": "quest",                 // quest | missable | secret
  "location": "Хелген",            // необязательно
  "giver": "Ралоф или Хадвар",     // необязательно, кто выдаёт
  "description": "1–3 предложения: суть задания без лишней воды.",
  "tips": ["Короткий практичный совет"],          // необязательно
  "hints": ["Где искать, что делать дальше"],   // необязательно: подсказки по прохождению, в приложении скрыты до нажатия
  "missable": "Что можно упустить и в какой момент это закрывается навсегда", // необязательно
  "repeatable": true,               // необязательно: радиант-задание, которое выдают снова и снова
  "related": ["side_bring_it"],     // необязательно: id пунктов из ЛЮБЫХ файлов, показываются ссылками со статусом
  "choices": [                     // необязательно — развилки, влияющие на прохождение
    {
      "id": "main_unbound_side",   // уникален глобально
      "question": "За кем бежать из Хелгена?",
      "options": [
        {
          "id": "ralof",           // уникален в пределах choice
          "label": "Ралоф (Братья Бури)",
          "result": "К чему приводит выбор",
          "locks": ["item_id"]      // необязательно: id пунктов ЭТОГО ЖЕ файла, которые становятся недоступны
        }
      ]
    }
  ]
}
```

Иконки категорий: dragon, swords, wolf, magic, lock, dagger, daedra, vampire, book, map, warning, star.

## Справочные разделы: навыки, зачарования, спутники

Категория может указать вкладку приложения: `"section": "skills" | "enchanting" | "followers" | "secrets"`
(по умолчанию — вкладка «Квесты»). У пунктов таких категорий `type` — `skill`, `enchantment` или `follower`.

Дополнительные поля пункта:

```json
"facts": [ { "label": "Мастер-тренер", "value": "Ларс… (Вайтран)" } ],  // таблица «параметр — значение»
"tags": ["marriage", "essential"]                                       // ключи меток из списка ниже
```

Ключи меток (переводит приложение, в JSON пишутся как есть):
- навыки: `warrior`, `mage`, `thief`
- зачарования: `weapon`, `armor`, `followers_yes` (работает на спутнике), `followers_no` (не работает), `unique` (нельзя изучить, только на особых предметах), `dlc`
- спутники: `marriage` (можно жениться), `essential` (бессмертный), `protected` (умирает только от героя), `housecarl`, `dlc`, `limited` (временный, только на время квеста)
- побочные задания: `favor` (мелкое поручение жителя), `thane` (засчитывается как помощь жителям владения для титула тана)
